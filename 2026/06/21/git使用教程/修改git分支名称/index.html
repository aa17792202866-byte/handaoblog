修改git分支名称

将 Git 默认上传或初始化的分支从 master 改为 main 非常简单。根据你的实际需求，可以分为以下几种场景来处理：

1. 修改本地全局默认分支（一劳永逸）

2. 将当前已有仓库的 master 重命名为 main

如果你当前的项目已经是 master 分支，想把它换成 main，请按以下步骤操作：

步骤一：在本地重命名分支

如果当前正处于 master 分支，直接运行：

步骤二：将新分支推送到远程仓库（如 GitHub/Gitee）

步骤三：修改远程仓库的默认分支（关键）

仅仅推过去是不够的，你还需要去你的代码托管平台（以 GitHub 为例）调整设置，否则直接 git push 依然可能会报错：

  1. 打开浏览器，进入该项目的 GitHub 页面。

  2. 点击 Settings -> Branches。

  3. 在 Default branch 选项中，点击右侧的切换按钮（双箭头），将默认分支从 master 改为 main，并点击 Update 确认。
