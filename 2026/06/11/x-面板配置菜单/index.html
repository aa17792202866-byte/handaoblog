x-面板配置菜单

这是 3X-UI 面板的管理菜单。通过输入不同的数字，你可以直接在 SSH 终端里对代理面板进行各种底层的控制。

为了方便你查阅，我把这 26 个选项翻译并归纳成了几个核心功能区：

🏗️ 基础安装与升级 (1 - 5)

  • 1. Install：安装 3X-UI 面板。

  • 2. Update：升级面板到最新版本。

  • 3. Update Menu：仅更新你当前看到的这个快捷菜单脚本。

  • 4. Legacy Version：切换或安装老旧的传统版本。

  • 5. Uninstall：彻底卸载 3X-UI 面板。

🔒 账户与面板设置 (6 - 10)

  • 6. Reset Username & Password：重置用户名和密码（忘记网页登录账号密码时用这个）。

  • 7. Reset Web Base Path：重置网页根路径（即自定义的 URL 后缀，比如 http://IP:端口/你的后缀）。

  • 8. Reset Settings：把面板的所有设置恢复到默认状态。

  • 9. Change Port：修改面板的网页访问端口。

  • 10. View Current Settings：查看当前面板的配置信息（包括当前的用户名、密码、端口和登录后缀）。

⚙️ 服务状态控制 (11 - 16)

  • 11. Start：启动 3X-UI 面板服务。

  • 12. Stop：停止面板服务。

  • 13. Restart：重启面板服务（修改完底层配置通常需要重启）。

  • 14. Restart Xray：仅重启 Xray 核心（节点断连或修改节点配置后使用）。

  • 15. Check Status：检查面板和 Xray 当前是否在正常运行。

  • 16. Logs Management：日志管理，可以查看面板运行日志或清理日志文件。

🚀 系统与高级管理 (17 - 26)

开机自启

  • 17. Enable Autostart：开启开机自动启动。

  • 18. Disable Autostart：关闭开机自动启动。

证书与安全 (19 - 23)

  • 19. SSL Certificate Management：常规 SSL 证书管理（申请、配置证书）。

  • 20. Cloudflare SSL Certificate：通过 Cloudflare API 自动申请证书（就是你之前选过的那个）。

  • 21. IP Limit Management：IP 限制管理（限制单账号最大连接设备数，防止被多人盗用）。

  • 22. Firewall Management：防火墙管理（这里面通常就包含你刚才想找的 Fail2ban 自动封禁 相关的快捷设置开关）。

  • 23. SSH Port Forwarding Management：SSH 端口转发管理。

性能与工具 (24 - 26)

  • 24. Enable BBR：开启 BBR 网络加速（强烈推荐！能显著提升网络吞吐量和降低丢包，如果你还没开过，建议顺手运行一下）。

  • 25. Update Geo Files：更新路由规则文件（geoip.dat 和 geosite.dat），用来精准识别国内和国外流量。

  • 26. Speedtest by Ookla：在服务器上运行 Ookla 官方测速，测测这台服务器的上下行真实带宽。

💡 一个小提示：既然你在上一步尝试手动配置 Fail2ban，你其实可以直接在当前菜单输入 22 (Firewall Management) 进去看看，有些版本的 3X-UI 菜单在防火墙管理里提供了自动帮你安装和配置 3x-ipl 监狱的自动化开关，能省去不少手动敲命令的麻烦。
