查看git用户名邮箱和推送仓库地址

要查看 Git 当前的配置（用户名、邮箱）以及当前项目连接的远程仓库（推送和下载地址），你可以使用以下几个核心命令。

1. 查看当前的用户名和邮箱

Git 的配置分为 当前项目（局部） 和 全局 两种。Git 会优先使用当前项目的配置，如果没有，则使用全局配置。

  • 查看当前项目生效的配置（推荐）：

    Bash

  • 查看全局（所有项目默认）的配置：

    Bash

  • 一键查看所有配置列表（包含用户名、邮箱和其他设置）：

    Bash

2. 查看推送（Push）和下载（Fetch/Pull）的远程仓库

你需要在项目根目录下运行以下命令：

Bash

运行后的输出示例：

Plaintext

💡 如何解读输出结果？

  • origin：这是远程仓库在本地的别名（Git 默认叫 origin）。

  • (fetch)：后面对应的 URL 是你下载/拉取代码的仓库地址。

  • (push)：后面对应的 URL 是你推送/上传代码的仓库地址。

  • 注意：通常这两个地址是一样的，但在某些特殊工作流（如 Fork 开源项目）中，它们可能会指向不同的仓库。

3. 查看更详细的仓库分支对应关系

如果你不仅想看仓库地址，还想看本地分支正在和远程的哪个分支进行同步，可以使用：

Bash

(注：如果你的远程仓库别名不是 origin，请将命令最后的 origin 替换为你的实际别名。)

这个命令会清晰地显示出：

  • 远程仓库的实际 URL

  • 你当前处于哪个分支

  • 执行 git pull 和 git push 时，本地分支会对应到远程的哪个具体分支。
