软件测试linux笔记

四、进程管理

1. 静态查看进程

命令 说明
ps -aux 显示系统所有进程
ps -aux grep 进程名
ps -ef 查看父进程号（ppid）

2. 动态查看进程

命令 说明
top 动态显示系统所有进程（默认每3秒刷新一次）
top -d 数字 动态显示所有进程，每 n 秒刷新一次
top -i 不显示闲置或僵死的进程
top -p 进程号 动态查看某指定进程

快捷键操作说明

  • top 命令的执行结果，默认按照 CPU 占有率从高到低排序：
    • 输入 M：切换排序规则为按照内存占有率从高到低排序
    • 输入 **N**：切换排序规则为按照 PID 从高到低排序
    • 输入 **P**：切换排序规则为按照 CPU 占有率从高到低排序
  • 退出：输入 q 或按下 Ctrl + C

3. 关闭进程

命令 说明
kill 进程号 通过进程号关闭进程
killall 进程名 通过进程名关闭进程
kill -9 进程号 通过进程号强制关闭进程
killall -9 进程名 通过进程名强制关闭进程

4. 监控网络状态

命令 说明
netstat -anp 监控网络状态及端口占用情况
`netstat -anp grep 端口号`
`netstat -anp grep 服务名`
netstat -tlnp 查看哪些端口在监听

5.用户权限和管理

1、修改权限

方式一：通过字母结合 +, -, = 的方式修改

命令格式：

作用： 修改文件权限

参数说明：

  • 用户类型：
    • u：表示所有者 (User)
    • g：表示所属组 (Group)
    • o：表示其他人 (Others)
    • a：表示所有人 (All)
  • 操作符：
    • +：表示增加权限
    • -：表示减少权限
    • =：表示刷新/赋予指定权限

方式二：通过数字修改权限

命令格式：

作用： 修改文件权限为：所有者拥有读写的权限，所属组拥有写和执行的权限，其他人拥有读和执行的权限。

数值对应表：

  • r (Read, 读权限) $
    ightarrow$ 4
  • w (Write, 写权限) $
    ightarrow$ 2
  • x (Execute, 执行权限) $
    ightarrow$ 1

(例如：6 = 4+2 [读写]；3 = 2+1 [写执行]；5 = 4+1 [读执行])

注意： 以上两种方式对目录进行权限修改时，需要加上 -R，可以对目录权限进行递归修改。

一、 权限字符区（前 10 个字符：-rwxr--r--）

这 10 个字符（索引 0-9）分为 4 个部分：

  1. 第 0 位（-）：文件类型

    • -：普通文件（如 .txt、.sh、二进制可执行文件等）。

    • d：目录（Directory）。

    • l：软链接/符号链接文件（Link）。

    • c：字符设备文件（Character，如键盘、鼠标、串口设备）。

    • b：块设备文件（Block，如硬盘、光驱等存储设备）。

  2. 第 1-3 位（rwx）：文件所有者（Owner / User）的权限

    • r（Read，读）：可查看文件内容。

    • w（Write，写）：可修改文件内容。

    • x（eXecute，执行）：可作为程序/脚本运行。

    • _当前状态_：所有者拥有 读、写、执行 完整权限。

  3. 第 4-6 位（rw-）：所属组（Group）的权限

    • 指与该文件同在一个用户组的其他用户所拥有的权限。

    • - 表示缺少对应权限。

    • _当前状态_：同组用户拥有 读、写 权限，但无执行权限。

  4. 第 7-9 位（r--）：其他用户（Other）的权限

    • 指既不是所有者、也不在所属组里的其他所有用户。

    • _当前状态_：其他用户仅拥有 读 权限，无写和执行权限。

二、 其他属性字段

  • 1（硬链接数/子目录数）：

    • 如果是文件：表示该文件的硬链接数量（当前为 1，即仅有自身一个文件名指向此数据）。

    • 如果是目录：表示该目录下包含的子目录数量（包含自身 . 和上级目录 ..）。

  • root（文件所有者）：

    • 该文件属于 root 用户。

  • police（文件所属组）：

    • 该文件归属于 police 用户组。

  • 1213（文件大小）：

    • 默认单位为字节（Byte），即该文件大小为 1213 字节。（如果是目录，通常显示为块大小，如 4096）。

  • Feb 2 09:39（最后修改时间）：

    • 文件最近一次被修改的日期和时间（2 月 2 日 09:39）。

  • abc.txt（文件名）：

    • 目标文件或目录的名称。
