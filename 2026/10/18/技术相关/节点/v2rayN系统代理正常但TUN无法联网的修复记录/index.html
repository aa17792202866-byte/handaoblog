v2rayN 系统代理正常，但 TUN 无法联网的修复记录

记录一次 Windows 下 v2rayN 系统代理可用、开启 TUN 后无法联网的问题。本次通过排除代理链入口 IP，并将直连 DNS 改为 DoH 恢复连接；之后分别撤销任意一项都会再次无法联网，因此当前环境下两项均需保留。

故障环境与现象

本次使用 v2rayN V7.25.6、Xray 26.9.9，节点采用链式代理。TUN 使用 sing-box，开启自动路由和旧版 TUN 保护，协议栈为 gvisor，严格路由关闭。

主要现象：

  • 关闭 TUN，使用系统代理可以正常上网。
  • 开启 TUN 后，网页无法正常访问。
  • Windows 显示 singbox_tun 无法访问 Internet。

Windows 的联网状态提示不能单独证明 TUN 故障。本次同时存在实际访问失败，因此继续检查核心日志与生成配置。

日志里的关键线索

除了 v2rayN 主窗口日志，还检查了程序目录下的 guiLogs 和 binConfigs/configPre.json。这些路径是本次版本的实际文件位置，其他版本可能不同。

如果 Reality 前面还有前置代理，应根据实际链路排除最先连接的前置服务器。通过 IPv6 连接时，单个服务器地址使用 /128。
