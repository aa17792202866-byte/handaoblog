CSS选择器与元素定位笔记

本文整理 CSS 选择器的常用写法，包括基础选择器、层级关系、位置匹配和多条件组合，并记录 Firefox 开发者工具中遇到的查询现象。

1. 基础选择器

CSS 选择器用于匹配 HTML 元素，可以用于页面样式、JavaScript 查询和 Selenium 元素定位。

类型 写法 示例 含义
标签选择器 标签名 div 匹配所有 div 元素
ID 选择器 #id值 #count 匹配 id 为 count 的元素
类选择器 .类名 .head 匹配 class 中包含 head 类名的元素
属性选择器 [属性名="属性值"] [type="password"] 匹配 type 属性为 password 的元素

3. 按兄弟元素位置匹配

这些伪类用于按位置选择元素，不会改变元素顺序。位置从 1 开始计算。

写法 含义
:nth-child(n) 是父元素的第 n 个子元素
:first-child 是父元素的第一个子元素
:last-child 是父元素的最后一个子元素

计算位置时，包含所有标签类型的兄弟元素，只统计元素节点，不统计文本和注释节点。

span:nth-child(2) 的意思是：元素既是 span，又是父元素的第 2 个子元素，并不是“第 2 个 span”。

6. 常见写法对比

写法 含义
div, span 所有 div 或 span
div span div 内部任意层级的 span
div > span div 的直接子元素 span
div.box 包含 box 类的 div
div .box div 内部包含 box 类的后代元素
.a.b 同时包含 a 和 b 两个类的元素
.a, .b 包含 a 类或 b 类的元素

记忆要点：逗号表示“或”，空格表示后代关系，> 表示直接子元素，条件连写表示“同时满足”。

  • 在 Firefox 查看器的搜索框输入 div,span，显示“无匹配”。
  • 在控制台执行 document.querySelectorAll("div, span")，返回 NodeList(189)。
