1. while 循环：根据条件重复执行

2. range()：生成整数序列

range() 返回一个表示整数序列的 range 对象，常与 for 配合使用。

参数含义默认值
start开始值，包含在序列内（序列非空时）0
stop结束边界，不包含在序列内必须提供
step步长1

开始值、结束值可以是正整数、负整数或 0；步长可以为正或负，但不能为 0。

记住：包含开始值，不包含结束值。 正步长向大数方向递增，负步长向小数方向递减；方向不匹配时，得到空序列。

扩展：六种实现方式

下面按六种写法分别实现。它们是同一道题的不同写法，其中普通 for 循环与前面的基础解法属于同一种思路。

每个方法的主代码块都可以单独运行：输入字符串后，默认查找第 2 个恰好出现 1 次的字符，也可以修改 m 和 n。输入 gbgkkdehh 时，六种方法都会得到 d。

统一约定：m 和 n 为正整数；候选字符按第一次出现的顺序排列，同一字符只计入一次。示例对 m、n 的取值范围和候选数量进行了检查。

方法一：列表推导式与 dict.fromkeys()

列表表达式的for循环格式

dict.fromkeys(text) 将字符作为字典的键，重复字符只保留一个键。在 Python 3.7 及以上版本中，字典保证保留插入顺序，因此可以按字符第一次出现的顺序去重。

例如，list(dict.fromkeys("gbgkkdehh")) 得到 ['g', 'b', 'k', 'd', 'e', 'h']。列表推导式再从中筛选出现次数等于 n 的字符。

这行代码可以读成：“遍历去重后的字符，如果字符出现了 n 次，就把它放入结果列表。”如果暂时看不懂推导式，可以先学习方法二。

方法二：for 循环与成员判断

外层 if 判断出现次数，内层 if 防止重复添加。按原字符串顺序遍历，就能保持字符第一次出现的顺序。

两个判断也可以合并成 if text.count(char) == n and char not in result:，与前面的基础写法效果相同。这里直接遍历字符串，不需要将字符串转换为列表；result 只是用来保存候选字符。

方法三：通过 index() 判断首次出现的位置

text.index(char) 返回字符第一次出现的索引。只有当前索引 i 等于这个位置时，才将符合次数要求的字符加入结果。

例如，g 在示例字符串中的索引为 0 和 2，而 text.index("g") 始终为 0。当 n = 2 时，只会在 i = 0 时添加 g，不会在 i = 2 时再次添加。

方法四：while 循环

使用 i 记录当前位置，通过 text[i] 取出字符，判断方法与普通 for 循环相同。

i += 1 必须在每轮循环中执行。 这里将它放在 if 外面，避免遇到不符合条件的字符时，索引无法前进而陷入死循环。

方法五：使用字典累计次数

第一次循环用字典统计每个字符的出现次数。对于 gbgkkdehh，得到：

第二次循环直接遍历字典的键，挑选出现次数等于 n 的字符。字典的键不会重复，因此不需要再判断 char not in result。

这里利用 Python 3.7 及以上版本中字典保留插入顺序的特性。与反复调用 text.count() 相比，这种方法只扫描原字符串一次来累计次数，处理较长字符串时更合适。

方法六：复制列表遍历，删除不符合条件的字符

这个方法先将字符串转换成列表，再遍历副本、修改原列表：

  • list(text)：将字符串转换为字符列表。

  • chars[:]：创建列表的副本，循环遍历的是副本。

  • chars.remove(char)：从原列表 chars 中删除一个不符合条件的字符。

  • text.count(char)：始终在原字符串中统计次数，避免删除过程改变统计依据。

筛选后仍需去重。例如 n = 2 时，筛选得到 ['g', 'g', 'k', 'k', 'h', 'h']，去重后才是 ['g', 'k', 'h']。

字符串不能像列表一样原地删除字符，因此这种“复制后删除”的写法需要转换成列表。若不想转换，使用方法二即可。

刚学习循环时，可以先掌握方法二，再理解方法三和方法四；学过字典后，再看方法一和方法五。方法六主要用于练习“遍历副本、修改原列表”。

不要用无序的集合直接替代有序去重步骤，否则无法保证题目要求的首次出现顺序。此外，第 m 个字符对应 result[m - 1]，取值之前必须保证 1 <= m <= len(result)。

五、易错点速查

容易混淆的地方正确理解
range() 的结束值不包含在生成的序列中
break 与 continue前者结束循环，后者跳过本轮剩余代码
input() 输入数字返回的仍是字符串，按数值处理前需要转换
“同时被 7 和 8 整除”使用 and，不是 or
len() 与 enumerate()前者返回长度，后者逐次提供编号和元素
排序与逆序排序按大小排列，逆序只颠倒已有顺序
reverse() 的返回值原地修改列表，返回 None
遍历时删除元素倒序按索引删除可避免元素前移造成漏检
列表索引与“第几个”索引从 0 开始，第 m 个对应索引 m - 1
