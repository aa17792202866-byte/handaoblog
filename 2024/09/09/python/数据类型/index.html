Python 数据类型笔记

Python 主要有 7 种数据类型，其中 4 种简单的，3 种复杂的。

1）4 种简单的数据类型

类型 说明 示例
int 整数 100、-5、0
float 浮点型（小数型） 3.14、-0.5
str 字符串 "hello"、'Python'
bool 布尔型，只有 True 和 False True、False

2）3 种复杂的数据类型

类型 说明 示例
list 列表（有序、可修改） [1, 2, 3]
tuple 元组（有序、不可修改） (1, 2, 3)
dict 字典（键值对） {"name": "Tom"}
