1. vi 的作用

vi 是 Linux 系统中常用的文本编辑器，可以用于：

  1. 新建文件
  2. 修改文件
  3. 查看文件

例如：

打开文件
|
↓
命令模式（默认）
|
| i
↓
插入模式（写文字）
|
| Esc
↓
命令模式
|
| :
↓
底行模式（保存退出）

打开后默认就是命令模式。

作用：

  • 移动光标

  • 删除

  • 复制

  • 粘贴

  • 查找

注意：

命令模式下直接输入字母不会写入文件，
而是执行 Vim 命令。
