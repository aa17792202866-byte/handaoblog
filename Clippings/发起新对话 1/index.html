函数的传参方式有哪些

Gemini

Python 函数的传参方式主要有以下 6 种：

1. 位置参数（Positional Arguments） 按定义时的顺序依次传入，实参与形参的位置必须一一对应。

2. 关键字参数（Keyword Arguments） 通过 形参名=值 的形式指定传参， 无需关注参数顺序 。

3. 默认参数（Default Arguments） 在定义函数时给形参设置默认值。调用时若不传该参数，则使用默认值。

4. 可变位置参数（ args） 使用 *args 接收任意数量的无名参数，在函数内部会被打包成一个 元组（tuple） *。

5. 可变关键字参数（ kwargs） 使用 **kwargs 接收任意数量的具名参数，在函数内部会被打包成一个 字典（dict）。

* 6. 强制限定传参方式（/ 和 ）

  • / 左边的参数 必须使用位置参数 。
  • * 右边的参数 必须使用关键字参数 。

组合使用时的固定顺序 若在同一个函数中组合多种传参方式， 定义时的形参顺序必须严格遵循 ：

位置参数 $\rightarrow$ *args $\rightarrow$ 默认参数 $\rightarrow$ **kwargs
